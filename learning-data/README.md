# 本项目的阅读记录

本目录只用于 `make web-serve` 本机版。GitHub Pages 在线版的记录保存在访问者自己的浏览器中，不会写入或上传到这里。需要把本机进度带到线上时，在本机「我的学习」导出 JSON，再在在线版导入即可。

运行 `make web-serve` 后，网页会自动将阅读位置、已读章节、收藏、笔记、小测和复习状态保存到这里的 `progress.json`。重启服务、换浏览器或重新构建网页后，仍可从同一份记录继续。

- `progress.json`：当前记录，由本机服务器原子写入。
- `progress.previous.json`：上一次成功保存的版本，用于手动恢复。
- 两个文件都已加入 `.gitignore`，不会随 Git 提交上传，但会随整个项目文件夹的备份保留。
- `make clean` 只删除构建目录，不影响这里。
- 网页还会保存浏览器草稿，以便断线后重试。以页面的“已保存到项目”状态为写入成功的依据。
- 如需恢复前一版本，先停止服务，备份当前文件，再将 `progress.previous.json` 复制为 `progress.json`，重新启动服务。也可以使用网页中的记录导出与导入。

这是本机单用户记录，不是云同步服务。请勿手动同时编辑文件和网页；两个页面同时修改时会提示冲突，防止后保存的页面覆盖另一份笔记。
