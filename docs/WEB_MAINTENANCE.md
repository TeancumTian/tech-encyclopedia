# 互动学习网页维护说明

「原来如此」面向零基础成年人：从生活问题进入知识，用可操作实验观察因果，再用小测和自己的笔记检查理解。当前版本含 4 条路线、20 节导学、6 个实验；其余词条提供完整百科阅读和关联导航。

## 本机启动

```bash
make web-serve
```

打开 http://127.0.0.1:4173 。Python 3.9+ 即可构建和预览，无需安装 npm 包。服务只监听本机；关闭终端或按 Ctrl+C 后停止。修改源码后重新运行 `make web`，刷新浏览器即可，服务无须重启。

```bash
make web        # 构建到 build/web
make web-check  # 书稿检查 + 构建 + JS 语法检查 + Node 内置测试
```

检查需要 Node.js 20+。也支持 `npm run build`、`npm test` 和 `npm start`；首次运行测试或服务前先构建。应用是静态网站，不能直接双击 `index.html` 使用，浏览器需要通过 HTTP 读取资料。

`data/entries.json` 与 `build/web/` 都是产物。前者按原项目约定提交，后者不提交。不要直接修补产物。

构建器读取原有 `@entry` 与字段标记，保留字段、图解、相关词条与原理。展示时将书内的 `[[id|显示名]]` 转成网页链接，所有文本先转义再格式化。构建时检查词条缺失、重复、交叉引用及图路径，发现问题直接失败。

## 增加一节导学

1. 在 `web/learning.js` 的 `content` 添加已有词条 ID。
2. 写一个熟悉的生活类比；说明类比的适用范围，避免把类比当物理机制。
3. 写一道检查因果理解的选择题、三个选项、正确答案索引（从 0 开始）和反馈。反馈说明原因，而不仅是对错。
4. 把词条放入合适的 `pathways.ids`，保持递进顺序；建议每条路线 5 节左右。
5. 如果新增事实或数字，按出版标准核实，并在 `front/sources-*.md` 留下日期和依据。不要把原书稿核实时间写成网页打开时的日期。
6. `make web-check` 后，在浏览器走一次错误答案、正确答案、标记完成和下一节。

百科词条可以自主标记理解；有小测的导学必须先答对才能标记学会。「学会」是用户自评，不代表测评认证。再次点击可撤销。

## 实验模型

| 实验 | 可操作部分 | 模型与边界 |
| --- | --- | --- |
| 逻辑门 | 两个输入和 AND / OR / XOR | 确定性真值表；不模拟电气延迟 |
| 二进制 | 八个位开关 | 一个字节的无符号整数，0–255；挑战值 42 |
| 电流 | 电压 1–24 V、电阻 1–100 Ω | 理想直流欧姆元件，I=U/R，P=UI；忽略温度变化 |
| 高压输电 | 电压 10–100 kV | 固定 1000 kW 与线路电阻 10 Ω，以 I=P/U、损耗 I²R 演示比例关系；不是完整电网潮流模型 |
| 梯度下降 | 学习率 0.05–1.2、单步、重置 | L=x²，更新 x←x−α·2x；从 x=4 开始，展示收敛、振荡、发散。超过范围停止计算 |
| 数据包 | 接收、重传、重置 | 固定示例演示乱序、丢包与 TCP 式重传重排；明确 IP 不保证可靠有序，真实包按字节划分 |

新增实验时把数学逻辑放进 `models.js`，为边界、规律和反例写测试，界面说明单位与简化假设。按钮与输入控件要有可读名称，反馈用文本呈现，不只靠颜色。

## 学习记录

记录保存在浏览器当前 origin 的 `localStorage`，键为 `tech-encyclopedia-learning-v1`。字段包括已学、收藏、答对的题目、上次词条和个人笔记。没有账户或云同步；清除网站数据、改端口或换浏览器会使用不同的存储空间。

「我的学习」支持 JSON 导出和导入合并。导入只接受版本 1、5 MB 以内的文件；过滤已经不存在的词条 ID，笔记限 5000 字。集合去重，同一条笔记优先保留当前浏览器版本。存储空间不足时提示导出，页面仍可继续使用。

升级数据结构时需提供兼容读取或显式迁移，不得无声清空学习记录。修改词条 ID 时同步设计旧 ID 的迁移。

## 浏览器验收

每次更改相关功能，检查对应路径即可：

- 首页逻辑门可点，路线有实际条目，前后导航有效。
- 搜索中文、英文、正文关键词；领域、核心图解筛选；零结果及翻页。
- 原理到词条、词条到原理、相关词条、图解放大和书稿来源。
- 六个实验的输入、输出、挑战及重置；大步长发散、数据包重传。
- 小测错题解释、正确反馈、标记完成、取消收藏、笔记刷新后持久化。
- 导出再导入；损坏文件不得覆盖已有进度。
- 窄屏与桌面无横向溢出；键盘可操作；减少动态效果偏好生效。

## GitHub 与发布

用户于 2026-10-09 选择先在本机使用。仓库保持私有，本次不配置公开网站、账户或定时任务。

`.github/workflows/check-web.yml` 在主分支推送与 PR 上运行检查，并生成 `interactive-encyclopedia` 构建包。原 PDF 工作流保留。需要在线发布时，可将 `build/web/` 部署至静态托管；资源都使用相对路径、页面使用 hash 路由，支持子路径部署。

公开网站会公开所部署的书稿，即使 GitHub 源码仓库仍私有。实际发布前由用户选择访问范围，再配置相应平台，不把「私有源码」等同于「私有网站」。

## 后续迭代顺序

优先根据实际学习反馈改进 20 节导学，再扩充能源、航天等领域实验。不要一次为全部词条机械生成同一种选择题。现有书稿事实沿用原核实记录，并未因为增加交互而重新全面事实审校。
