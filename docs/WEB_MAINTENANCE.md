# 互动学习网页维护说明

「原来如此」面向零基础成年人：从生活问题进入知识，用可操作实验观察因果，再用小测和自己的笔记检查理解。全书内容完整可读：997 词条、59 原理、17 篇导读与地图、20 份前置与来源文稿、726 项年表及中英文索引，共 1098 个连续阅读小节、183 张图解。现有 7 条路线、35 节专门编写的导学与小测、11 个实验，以及覆盖全部词条的翻卡回想和复习安排。另有深色模式、朗读、按需加载，以及给搜索引擎和无 JavaScript 读者用的纯文本词条页。

## 在线阅读与浏览器记录

在线入口为 https://teancum.me/tech-encyclopedia/ 。GitHub Pages 自动沿用账号已有的 `teancum.me` 域名，已启用强制 HTTPS；`https://teancumtian.github.io/tech-encyclopedia/` 自动跳转到这里。用户于 2026-10-09 后续明确选择仓库公有、网页公开，线上记录暂存浏览器并保留导入导出，替代此前仅本机/私有的发布约束。

静态构建中的 `runtime-config.json` 使用 `browser` 模式，`web/browser-storage.js` 直接读写 localStorage，不请求 `/api/progress`。存储键按部署路径隔离（`tech-encyclopedia-browser-v2:/tech-encyclopedia/`），刷新保留阅读锚点、已读、笔记、小测与复习。网页更新不会清空记录；清除网站数据、换浏览器或设备不会自动保留原数据。需要跨设备或从本机版迁移时使用 JSON 导出/导入。

保存失败时明确提示并保留页面内数据用于导出。检测到另一页面改动时保留本页草稿并提示先导出再载入已保存记录；损坏存档不会自动覆盖，明确清空后才能重置。本功能没有账户或云同步。

## 中文、English 与中英对照

顶部语言菜单及专注阅读工具条均可切换语言。英文覆盖界面、全书正文、图解、导学、小测与实验反馈；对照模式在中文段落下显示英文，并提供可展开的英文图解。原中文书稿和 PDF 排版保持独立。

三种模式共用内容 ID、阅读锚点、已读状态、笔记、收藏和复习安排。`prefs.language` 保存语言选择，旧记录默认中文；切换语言先捕获阅读锚点，再在新排版恢复。JSON 导入会保留当前页面的偏好，个人笔记原样显示。英文模式仍可用中文、英文或正文关键词搜索；中文索引保留原拼音排序。

切换语言保留当前实验参数、小测选择与反馈、复习卡片和队列位置，以及知识图谱的筛选条件。离开该页面会重置临时实验和答题状态，已经保存的学习记录不受影响。

翻译数据按 `en.auto.json` → `ui.en.json` → `en.json` 的顺序合并，以编辑覆盖为准。正常构建不使用在线翻译服务或模型。详细编辑流程见 [翻译维护说明](../translations/README.md)。英文采用机器辅助翻译与编辑修订，未对原书全部历史和数字重新事实审校；核实时间仍按原稿。

改动中文后必须补齐对应译文。界面改动还需重新提取 `translations/ui.source.json`；构建校验源文件摘要、全书和 SVG 覆盖、交叉引用 ID 与模板占位符。缺失翻译阻止发布，避免上线半中文页面。英文图解在构建时生成到 `build/web/en/`，保留原图形结构并调整标签字号。

## 本机启动

```bash
make web-serve
```

打开 http://127.0.0.1:4173 。Python 3.9+ 即可构建和预览，无需安装 npm 包。服务只监听本机；关闭终端或按 Ctrl+C 后停止。修改源码后重新运行 `make web`，刷新浏览器即可，服务无须重启。

```bash
make web        # 构建到 build/web
make web-check  # 书稿检查 + 构建 + JS 语法 + Python 存储/HTTP + Node 测试
```

检查需要 Node.js 20+。也支持 `npm run build`、`npm test` 和 `npm start`；首次运行测试或服务前先构建。网页前端是静态文件，本机 Python 服务同时提供项目保存 API；不能直接双击 `index.html` 使用。普通静态服务器提供完整浏览器存档模式；项目存档必须用 `make web-serve`，它动态返回项目模式配置。线上构建文件始终保留浏览器模式。

测试写入功能时，另开端口及独立数据目录，例如 `python3 scripts/serve_web.py --port 4174 --data-dir /tmp/encyclopedia-reader-qa`。不要把验收笔记写入用户的真实进度。

## 增加一节导学

1. 在 `web/learning.js` 的 `content` 添加已有词条 ID。
2. 写一个熟悉的生活类比；说明类比的适用范围，避免把类比当物理机制。
3. 写一道检查因果理解的选择题、三个选项、正确答案索引（从 0 开始）和反馈。反馈说明原因，而不仅是对错。
4. 把词条放入合适的 `pathways.ids`，保持递进顺序；建议每条路线 5 节左右。
5. 如果新增事实或数字，按出版标准核实，并在 `front/sources-*.md` 留下日期和依据。不要把原书稿核实时间写成网页打开时的日期。
6. `make web-check` 后，在浏览器走一次错误答案、正确答案、标记完成和下一节。

百科词条可以自主标记理解；有小测的导学必须先答对才能标记学会。「学会」是用户自评，不代表测评认证。再次点击可撤销。

## 实验模型

| 实验 | 可操作部分 | 模型与边界 |
| --- | --- | --- |
| 逻辑门 | 两个输入和 AND / OR / XOR | 确定性真值表；不模拟电气延迟 |
| 二进制 | 八个位开关 | 一个字节的无符号整数，0–255；挑战值 42 |
| 电流 | 电压 1–24 V、电阻 1–100 Ω | 理想直流欧姆元件，I=U/R，P=UI；忽略温度变化 |
| 高压输电 | 电压 10–100 kV | 固定 1000 kW 与线路电阻 10 Ω，以 I=P/U、损耗 I²R 演示比例关系；不是完整电网潮流模型 |
| 梯度下降 | 学习率 0.05–1.2、单步、重置 | L=x²，更新 x←x−α·2x；从 x=4 开始，展示收敛、振荡、发散。超过范围停止计算 |
| 数据包 | 接收、重传、重置 | 固定示例演示乱序、丢包与 TCP 式重传重排；明确 IP 不保证可靠有序，真实包按字节划分 |
| 火箭方程 | 推进剂占起飞质量 50–95%、喷气速度 2.0–4.5 km/s | 单级理想火箭，Δv = 喷气速度 × ln(起飞质量 ÷ 烧完质量)；与书中入轨约需 9.4 km/s（含阻力和重力损失）比较。不模拟分级、推力和飞行轨迹 |
| 卡诺效率 | 高温端 100–1500 °C、低温端 0–100 °C | 理想可逆热机上限 1 − T冷 ÷ T热，温度换算为开尔文；不含摩擦、散热等真实损失 |
| PCR 倍增 | 循环 0–40 轮、每轮效率 50–100% | 从 1 个分子开始，份数 = (1 + 效率)^轮数；真实反应后期原料减少会放缓，模型不模拟平台期 |
| 移位密码 | 英文明文、密钥 0–25、破解滑块 | 只移动 26 个英文字母，c = (p + k) mod 26；只有 25 种有效密钥，仅用于演示密钥与模运算 |
| 平方—立方定律 | 放大倍数 1–10 | 几何相似、材料不变：面积 k²、体积与重量 k³、底面压力 k；不模拟结构形式和材料的改变 |

新增实验时把数学逻辑放进 `models.js`，为边界、规律和反例写测试，界面说明单位与简化假设。按钮与输入控件要有可读名称，反馈用文本呈现，不只靠颜色。

## 本机项目学习记录

记录自动写入项目 `learning-data/progress.json`，保留上一版 `progress.previous.json`，均不提交 Git。它们位于 `build/` 外，重新构建、`make clean` 和重启服务不会清除。备份与人工恢复方法见 [学习数据说明](../learning-data/README.md)。

文件格式为 `{format: 2, revision, updatedAt, progress}`。进度含已学、收藏、答对与错题、每节阅读位置与已读状态、上次阅读小节、个人笔记、复习安排及阅读偏好。阅读位置用内容锚点与段内偏移保存，锚点不存在时回退为页面比例；「已读」由用户显式标记，与「学会」独立。

服务只监听 `127.0.0.1`，校验本机 Host 和写入 Origin / 自定义请求头；仅提供构建目录与 `/api/progress`，不暴露项目目录。保存使用临时文件、fsync 与原子替换；版本号不一致返回 409，页面提示用户先导出草稿再载入项目版本，不默默覆盖另一个页面的记录。当前是本机单用户用途，不是多人协作或云同步服务。

浏览器键 `tech-encyclopedia-project-v2` 保存本地草稿、待保存状态和版本号。失败时保留草稿，显示「未写入项目」并可重试；顶部「已保存到项目」才表示本次写入已确认。首次连接且项目尚无文件时，会迁移旧键 `tech-encyclopedia-learning-v1`。已有项目文件优先于干净的浏览器缓存；未保存草稿遇到版本变化时进入冲突提示。选择项目版本前另保留一份浏览器恢复副本。

「我的学习」支持版本 1 / 2、5 MB 以内的 JSON 导入合并和导出。过滤无效 ID，笔记限 5000 字；集合去重，同一条笔记、阅读记录与复习记录优先保留当前页面版本。升级结构或修改词条 ID 时必须维持兼容，不得无声清空个人数据。

翻卡为自我回想，展示原书定义与原理后，由用户选择「想起来了」或「还需巩固」。前者按 1、3、7、15、30 天复习，后者 10 分钟后再看；不会自动标为学会。20 节导学的错题可单独重练，答对后移出错题清单。这不等于为 997 个词条都编写了专门选择题。

## 浏览器验收

每次更改相关功能，检查对应路径即可：

- 首页逻辑门可点，路线有实际条目，前后导航有效。
- 搜索中文、英文、正文关键词；领域、核心图解筛选；零结果及翻页。
- 原理到词条、词条到原理、相关词条、图解放大和书稿来源。
- 十一个实验的输入、输出、挑战及重置；大步长发散、数据包重传；火箭 4.4 km/s 时 88% 不够而 89% 够、PCR 第 30 轮过十亿、移位密码往回 11 格破解、放大 5 倍压力 5 倍。
- 深色、浅色、自动三种配色切换与刷新后保持；专注阅读工具条里的切换按钮；图解在深色下保持浅色底。
- 朗读：开始、暂停后从同一句继续、调速、停止；切换页面或语言时停止；对照模式读中文、English 模式读英文。
- 纯文本页：`e/index.html` 能到达每个词条页，词条页的相关词条、原理、图解和「打开互动学习版」链接有效；`en/` 下为英文。
- 小测错题解释、正确反馈、标记完成、取消收藏、笔记刷新后持久化。
- 导出再导入；损坏文件不得覆盖已有进度。
- 全书前置、篇章导读与图、来源表格、726 项年表、997 条中英文索引与总表，前后节导航有效。
- 已读、字号、专注阅读、恢复锚点位置；重启服务并用没有旧缓存的 origin 打开，确认从项目文件恢复。
- 全词条/收藏/已读/到期翻卡、错题重练和复习安排；故障重试、并发冲突和备份不破坏用户记录。
- 窄屏与桌面无横向溢出；键盘可操作；减少动态效果偏好生效。
- 三种语言的正文、图解、长标题与实验反馈；专注模式下切换语言，笔记不翻译、已读与锚点保留；跨语言导入导出。
- 小测与错题重练：双语选项的中英文均在按钮内部，按钮随长文本增高；不要把编号的固定宽高套到 `.parallel-text`。同时检查小节编号与双语标题对齐。

## GitHub 与发布

仓库已获用户明确授权改为公有，并使用 GitHub Pages 公开网页。版权保留原有约定；仓库可见性改变不等于添加开源许可证。

`.github/workflows/deploy-pages.yml` 在 `main` 推送或手动触发时运行 `make web-check`，将 **仅 `build/web/`** 上传为 Pages artifact，再由依赖构建成功的 deploy job 发布。部署使用 `github-pages` environment 和最小 Pages/OIDC 权限；使用 concurrency 避免并发发布。仓库 Pages 设置选择 GitHub Actions（`build_type=workflow`）。

`.github/workflows/check-web.yml` 保留 PR/主分支检查，PDF 工作流继续独立运行。发布包不包含 `learning-data/`、Python 服务、Git 历史或私人 JSON。构建测试对这个边界和浏览器模式有断言。

所有资源用相对路径，路由使用 hash；在 `/tech-encyclopedia/` 子路径验收后发布。发布后确认 Actions 部署成功、HTTPS 页面返回 200，并在真实网址检查目录、图解、浏览器存档和窄屏布局。若需回滚，恢复上一个已验证提交的前端源码后重新构建部署，保留个人浏览器数据。

构建为前端模块、样式、书稿和翻译 JSON 的引用加入同一内容摘要版本，防止浏览器把旧代码与新译文混用。运行模式配置仍实时读取，不参与此缓存版本；发布不修改浏览器学习记录的存储键。

优先根据实际学习反馈改进 35 节导学，再为材料、制造、交通、农业、建筑、金融、环境、媒体等还没有导学的领域补路线和实验。不要一次为全部词条机械生成同一种选择题。现有书稿事实沿用原核实记录，并未因为增加交互而重新全面事实审校。

## 首屏按需加载

构建同时写出完整的 `book.json`、合并前的翻译目录（供测试和工具使用），以及阅读器实际请求的拆分文件：

- `book.core.json`：全部结构、名称、定义、导读与文稿，不含词条正文字段。首屏只下载它。
- `bodies/<领域>.json`：一篇的词条正文，打开该篇任一词条、做全文搜索或翻卡时才请求。
- `en.json`：界面、前置与来源文稿、名称、定义和图解标签的英文；`en/bodies/<领域>.json` 是对应篇的正文英文。两者只在选择 English 或中英对照后请求。

`app.js` 的 `ensureBodies` 和 `ensureTranslations` 负责请求与合并，页面在所需数据到齐后一次绘制；全文搜索先按名称和定义出结果，正文到齐后自动补全。运行时请求带与模块相同的 `?v=` 版本号（构建时替换 `__ASSET_VERSION__`），拆分文件也计入版本摘要。gzip 后中文首屏数据约 232 KB（原来两份共约 1.98 MB）。

## 深色模式

`prefs.theme` 取 `auto`、`dark`、`light`，和字号、语言一起存在 v2 进度里，旧存档默认 `auto`。`index.html` 头部的内联脚本在首屏绘制前读取存档或系统设置并给 `<html>` 加 `data-theme`，避免闪白；`theme.css` 只在 `data-theme=dark` 下覆盖配色。原书 SVG 是深色文字加透明底，所以图解和封面在深色模式下保留浅色卡片。新增界面元素要同时补 `theme.css`。

## 朗读

`speech.js` 使用浏览器的 `speechSynthesis`，不引入任何语音服务。它收集当前小节的标题、段落和列表，跳过小测、实验、笔记、表格和图注，按句群分段朗读并高亮当前段落。暂停是取消后从同一句群重读，在不支持原生暂停的浏览器上也可用。中文与对照模式朗读中文，English 模式朗读英文；优先选设备本地语音。注意：部分浏览器的语音由浏览器厂商在线合成，书稿文字会经由该语音服务处理，个人笔记从不朗读。没有语音合成功能的浏览器不显示按钮。年表、索引、总表等查阅页不提供朗读。

## 纯文本词条页与 sitemap

阅读器是单页应用，地址在 `#` 之后，搜索引擎、分享预览和不开 JavaScript 的读者只能到达首页。构建因此另外生成无脚本的 HTML：

- `e/<id>.html`、`p/<id>.html`、`e/index.html` 为中文；`en/e/`、`en/p/` 为英文。共 2114 页，内容与阅读器同源（书稿加 `translations/`）。
- 每页有 canonical、zh/en hreflang、Open Graph 和 schema.org `DefinedTerm`，并链接回阅读器的 `#/entry/<id>`。
- `sitemap.xml` 列出全部页面。站点地址由 `SITE_URL` 环境变量决定，默认 `https://teancum.me/tech-encyclopedia/`；换域名时在构建前设置它。`robots.txt` 只在域名根目录生效，本项目位于子路径，需要时在 Search Console 提交 `sitemap.xml`。
- 这些页面不读写任何学习记录。修改版式改 `scripts/static_pages.py` 和 `web/static.css`，不要手改产物。

## 英文版 PDF

`make pdf-en` 用 `tools/build_pdf.py --lang en` 排英文版：书稿每一行在 `translations/` 的合并目录里取英文，图解用构建时生成的英文 SVG，附录为年表、来源和 A–Z 索引（索引同时列出中文名）。任何一行缺译都会让构建失败并列出缺译内容。`--lang` 不改变中文输出：重构前后中文全书与样章的排版 HTML 逐字节一致。CI 的 `build-pdf.yml` 同时产出两份 PDF，发版时都挂到 Release。
